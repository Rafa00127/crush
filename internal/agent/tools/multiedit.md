Apply several find-and-replace edits to one file in a single call. Edits run sequentially, so later edits see earlier results. Each edit follows the same rules as `edit`: `old_string` must appear exactly once, whitespace-only differences are tolerated and reported, and a failed edit stops the batch. Prefer this over repeated `edit` calls when changing several spots in the same file; use `write` for a full rewrite.
